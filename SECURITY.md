# Security Policy

## Scope & intent

This repository is a **personal cybersecurity training lab**. It contains both
defensive tooling and deliberately offensive tooling (exploit code, brute-force
utilities, a vulnerable web app, honeypots, and similar). All of it is published
for **educational and research purposes** and is designed to be run **only in
isolated lab environments** that you own or are explicitly authorized to test.

Do not run the offensive tools against systems you do not own or have written
permission to assess. Misuse may be illegal; the author accepts no liability for
any misuse.

## Reporting a vulnerability

If you find a security issue in this repository's code — for example a tool that
behaves unsafely outside its intended lab context, an accidental secret in
history, or a dependency vulnerability — please report it privately rather than
opening a public issue:

1. **Preferred:** open a private report via GitHub's
   [Security Advisories](https://github.com/basil9099/cybersecurity-homelab/security/advisories/new)
   ("Report a vulnerability").
2. Alternatively, reach out through the
   [LinkedIn profile](https://www.linkedin.com/in/angus-dawson-92b035249) linked
   in the README.

Please include steps to reproduce and the affected path. As this is a personal
project, responses are best-effort, but genuine reports are appreciated and will
be acknowledged.

## Supported versions

This is a lab, not production software; only the `main` branch is maintained.
There is no formal release-support window.
